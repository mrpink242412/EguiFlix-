## 🎬 Qué es esto

**EguiFlix** es una plataforma de streaming personal hecha desde cero: una sola app web (funciona como PWA instalable) con estanterías de VHS navegables, fichas de cada película con póster, sinopsis y reparto, y un reproductor propio que funciona igual en el móvil, en el ordenador y en la tele (Android TV).

No es una demo ni una plantilla — es donde subo y organizo mis propios cortometrajes a medida que los voy terminando.

## ✨ Características

- 📱 **Multiplataforma de verdad**: móvil, PC y Android TV (navegable con mando: flechas + Intro), sin depender de reproductores de terceros.
- 📥 **Instalable como app** (PWA): icono propio, pantalla completa, sin barra de navegador.
- 🎥 Reproductor propio con controles a medida — nada de iframes ajenos que fallan al empotrarlos.
- 🎨 Estética de videoclub: estanterías de VHS, fichas con póster y ficha técnica, fondo tipo "ya viendo" al abrir cada película.
- 🆓 Alojado íntegramente con herramientas gratuitas (GitHub Pages + GitHub Releases para los vídeos).

## 🚀 Verlo

👉 **[Abrir EguiFlix](https://mrpink242412.github.io/EguiFlix-/)**

También se puede instalar como app: desde Chrome (PC, Android o Android TV), busca la opción "Instalar aplicación" en el menú del navegador.

## 🛠️ Hecho con

HTML, CSS y JavaScript puro — sin frameworks, sin build, un único archivo. Los vídeos se sirven directamente desde [GitHub Releases](../../releases).
